# corkboard-skill

Agent skill for [Corkboard](https://corkboard.wiki): a stdlib-only Python CLI
that reads and writes Corkboard wikis over the **HTTP API v1** with an API
token.

- **An MCP-alternative for CLI-driven agents** — Hermes, Claude Code, Codex, and
  any agent with a shell. No MCP client required; MCP stays a separate surface
  with its OAuth 2.1 flow.
- **Zero dependencies** — Python 3 standard library only (`urllib`, `json`).
  File-drop install: clone or curl into the agent's skills directory.

**Status: under construction — content lands soon.**

Documentation: [Corkboard docs — Skill](https://corkboard.wiki/docs/skill)
(Install, Configuration with `CORKBOARD_URL`/`CORKBOARD_TOKEN`, Usage,
Examples).
